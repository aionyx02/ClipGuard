桌面版會在 Phase 4 推出，用來保護瀏覽器以外的地方：在剪貼簿出現可疑指令時清掉它，並在你打開「執行」視窗或終端機時再提醒一次。只裝擴充功能或只裝桌面版都能完整運作，兩者都裝時可以互通。

發布後安裝方式會寫在這裡。先預告一個原則：

:::danger[不要為了安裝任何程式貼上終端機指令]
macOS 上第一次打開還沒經過 Apple 公證的 App 時，請用圖形介面：**系統設定 → 隱私權與安全性**，在頁面下方找到被擋下的 App，按 **強制打開**。

**PasteWarden 的安裝說明永遠不會要你在終端機貼上指令**。「為了安裝或驗證，請貼上這段指令」正是 ClickFix 攻擊的手法，看到這種說明時請提高警覺，不論它聲稱來自誰。
:::
