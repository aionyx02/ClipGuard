PasteWarden 的原則是：**你以為受到保護、實際上沒有的時候，一定要讓你看得到**。這一頁把保護不到的情況全部列出來。桌面版的設定頁有同一張表，而且會跟著目前的保護狀態即時更新。

## 兩種保護

- **複製當下**：你一複製，PasteWarden 就檢查剪貼簿。惡意指令（例如假驗證頁面要你貼進「執行」視窗的指令）會在這時候被清掉，剪貼簿裡已經沒有東西，所以**不論用哪種方式貼上都貼不出來**。
- **貼上前確認**：剪貼簿裡有機密（身分證字號、信用卡號、API key、私鑰、助記詞或你登記的密碼）時，在你貼上前先問你要取消、貼遮罩版還是貼原文。這一項**只認得鍵盤的貼上快速鍵**。

## 哪些貼上方式受到保護

| 貼上方式 | 複製當下（清掉惡意指令） | 貼上前確認（機密） |
|---|---|---|
| 鍵盤（Windows、Linux 的 Ctrl+V，macOS 的 Cmd+V） | 涵蓋 | 涵蓋（Linux 除外，見下方） |
| 右鍵選單的「貼上」 | 涵蓋 | **不涵蓋** |
| App 的「編輯 → 貼上」 | 涵蓋 | **不涵蓋** |
| 拖放 | 涵蓋 | **不涵蓋** |
| 遠端桌面的剪貼簿同步 | 涵蓋 | **不涵蓋** |
| 貼到系統管理員視窗（Windows） | 涵蓋 | **不涵蓋** |
| 開啟安全輸入時（macOS） | 涵蓋 | **不涵蓋** |
| 滑鼠中鍵（Linux 的 PRIMARY 選取） | **不涵蓋** | **不涵蓋** |

換句話說：惡意指令不論怎麼貼都會被擋下；**機密只有在用鍵盤貼上時才會先問你**。用右鍵、選單或拖放貼上機密時，PasteWarden 不會攔下來。

## Windows

- **系統管理員視窗**：以系統管理員身分執行的視窗（例如系統管理員終端機）收不到 PasteWarden 的按鍵攔截，所以機密貼進去前不會先問你。這不是完全沒有保護：惡意指令一樣在複製時清掉，打開終端機時的提醒也照常出現。剪貼簿裡有機密、你又切到系統管理員視窗時，PasteWarden 會跳一次通知提醒你。
- **複製後立刻貼上**：PasteWarden 會先等分析完成，最多 2 秒；超過時間就不貼，並跳出提醒。

## macOS

- **需要「輔助使用」權限**：要在你按 Cmd+V 時先攔下來，macOS 需要你在 **系統設定 → 隱私權與安全性 → 輔助使用** 允許 PasteWarden。不授權也可以使用，只是只會通知、不會在貼上前攔下來。
- **每次更新後要重新授權**：PasteWarden 沒有 Apple 的開發者簽章，macOS 會把更新後的版本當成另一個 App，所以舊的授權會失效，即使系統設定裡的開關看起來還是開的。請照下面的步驟重新加入：
  1. 打開 **系統設定 → 隱私權與安全性 → 輔助使用**。
  2. 在清單裡選 PasteWarden，按下方的 **−** 移除。
  3. 按 **+**，到「應用程式」資料夾選 PasteWarden，再把它的開關打開。
  4. 回到 PasteWarden，設定頁的保護狀態幾秒內會恢復正常。
- **安全輸入**：密碼欄位、終端機的「安全鍵盤輸入」和部分密碼管理器會開啟安全輸入，這段期間所有程式都收不到按鍵，PasteWarden 也攔不到貼上。macOS 不會告訴我們是哪個 App 開的。
- **約 250 毫秒的時間窗**：PasteWarden 每 250 毫秒檢查一次剪貼簿。複製後不到這個時間就按 Cmd+V，可能來不及攔下。
- **剪貼簿存取提示**：新版 macOS 可能在 PasteWarden 每次讀剪貼簿時詢問你。請到 **系統設定 → 隱私權與安全性**，把 PasteWarden 讀取剪貼簿的權限改成「永遠允許」。

以上都只需要在系統設定裡操作。**PasteWarden 永遠不會要你在終端機貼上指令。**

## Linux

- **不攔截貼上**：Wayland 不允許程式攔截按鍵；X11 雖然做得到，但會和你的快捷鍵工具衝突，所以這個版本在 Linux 上只在複製時清掉惡意指令並通知你，沒有貼上前確認。
- **不監聽 PRIMARY 選取**：選取文字就會放進 PRIMARY，用滑鼠中鍵就能貼出來。KeePassXC 等密碼管理器也會把密碼放在那裡。PasteWarden 不檢查 PRIMARY。
- **GNOME**：GNOME 不允許程式在背景讀剪貼簿，PasteWarden 在 GNOME 上無法自動檢查。可以從系統匣選「檢查剪貼簿」手動檢查，或改裝瀏覽器擴充功能。
- **COSMIC**：預設不開放背景讀剪貼簿，要設定環境變數 `COSMIC_DATA_CONTROL_ENABLED=1` 後重新登入。
- **XWayland**：如果桌面環境只能透過 XWayland 監聽，在原生 Wayland App 裡複製的內容可能收不到。
- **前景視窗**：在 Wayland 上拿不到前景視窗時，入口警告和允許清單會停用。
- **登記機密**：需要 Secret Service（例如 GNOME Keyring、KWallet）來保存金鑰；沒有的話無法登記機密，PasteWarden 不會改把金鑰寫進一般檔案。

## 瀏覽器擴充功能

只裝擴充功能時，保護範圍只到瀏覽器分頁裡面：網頁寫入剪貼簿時攔截、在網頁上貼上機密前先確認。瀏覽器以外的 App（終端機、「執行」視窗、聊天軟體）需要桌面版。詳見[功能說明](../features/)。
