PasteWarden（剪貼簿守門員）把剪貼簿當成一道信任邊界，兩個方向都守：

**進來的內容**

- **ClickFix / FileFix**：假的「我不是機器人」頁面叫你按 Win+R（或打開終端機、檔案總管網址列），貼上一段它偷偷放進剪貼簿的指令。
- **Pastejacking**：你選取並複製一段看起來無害的文字，網頁卻把剪貼簿換成別的東西。
- **隱藏字元**：零寬字元、BiDi 控制字元、同形字，讓你看到的和實際貼上的不一樣。
- **錢包地址掉包**：剪貼簿惡意程式把你複製的加密貨幣地址換成攻擊者的。

**出去的內容**

- 個資（身分證字號、手機號碼、信用卡號…）、API key、私鑰、助記詞，以及你自己登記的機密，被誤貼到網頁或聊天軟體。

## 怎麼運作

偵測引擎用 Rust 寫成，編譯成 WebAssembly 在瀏覽器裡執行。它會把指令一層層解混淆（最多 5 層），依照公開的[偵測規格](../../dev/generated/detection-rules/)給出三種判定：

| 判定 | 意思 | 擴充功能的做法 |
|---|---|---|
| 安全 | 沒有發現可疑內容 | 完全不介入 |
| 請注意 | 有可疑之處 | 放行，但顯示警告 |
| 已隔離 | 很可能是攻擊 | 把剪貼簿內容換成無害的提示文字，並說明原因 |

## 它不是什麼

PasteWarden 不是防毒軟體：它不掃描檔案、不監看程式行為。它專門處理「把攻擊者的文字搬進可以執行的地方」這一步，和防毒軟體互補。
