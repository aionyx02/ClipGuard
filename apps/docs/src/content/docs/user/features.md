## 網頁寫入剪貼簿時攔截

網頁可以用 `navigator.clipboard.writeText`、`document.execCommand('copy')` 或 `copy` 事件把內容放進你的剪貼簿。PasteWarden 在寫入的當下就判定：

- **已隔離**：寫入的內容換成一段無害的提示文字（「PasteWarden 已攔截這個網站放進剪貼簿的指令」），頁面上出現警告，說明來源網址、為什麼攔下來，並可以展開洋蔥視圖。如果你確定這段內容安全，可以按「我確定安全，放行一次」。
- **請注意**：內容照常寫入，但顯示警告。
- **安全**：完全不介入。

所有 frame（包括網頁裡嵌入的 iframe）都會檢查。

## 洋蔥視圖

攻擊指令常常用多層混淆躲避偵測：`^` 跳脫字元、反引號、字串拼接、Base64、`-EncodedCommand`……。洋蔥視圖把每一層解開的結果依序列出，最內層就是實際會執行的內容。裡面如果有機密，也會先遮罩。

## 貼上機密前確認

在網頁的輸入框貼上含有機密的內容時（身分證字號、信用卡號、API key、私鑰、助記詞…），PasteWarden 先攔下來問你：

| 選項 | 按鍵 | 結果 |
|---|---|---|
| 貼上遮罩版（預設） | Enter | 機密部分換成 `A1*******9` 這類遮罩 |
| 貼上原文 | 只能用滑鼠或 Tab 移過去再按空白鍵 | 原封不動貼上 |
| 取消 | Esc | 什麼都不貼 |

「貼上原文」刻意不能用 Enter 觸發，避免手快一路按 Enter 就把機密貼出去。密碼欄位不處理，那裡本來就該貼密碼。

## Pastejacking

你在網頁上選取並複製文字時，PasteWarden 會比對「你選取的」和「實際寫入剪貼簿的」。兩者不一樣，而且寫入的內容可疑時，就會警告。

## 外觀與語言

彈出視窗、設定頁和網頁上的警告層都跟隨系統的深淺色與語言（繁體中文、English）。設定頁可以手動切換。網頁上的警告層一律跟隨作業系統，不受網頁本身的配色影響，避免惡意網頁把警告藏起來。
