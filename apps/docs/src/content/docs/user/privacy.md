PasteWarden 經手的是你剪貼簿裡最敏感的東西，所以這些規則寫在架構裡，不能用設定關掉：

- **判定全部在本機**：偵測引擎是在瀏覽器裡執行的 WebAssembly，剪貼簿內容不會送到任何伺服器。
- **原文不落地**：剪貼簿原文不寫檔、不寫 log、不放進錯誤訊息或通知。
- **機密一律遮罩**：畫面上、紀錄裡出現的機密都是遮罩後的樣子。你自己登記的機密只存 HMAC-SHA256 雜湊，不存原文。
- **攔截紀錄只有摘要**：彈出視窗的「最近攔截」只存網域、時間、種類和遮罩字串。
- **預設零遙測**：沒有使用統計、沒有錯誤回報。
- **AI 功能預設關閉**：LLM 解說要你自己開啟並設定；偵測到個資或金鑰時，程式直接拒絕把內容送給雲端模型。AI 的判斷只能提高風險等級，不能把本機引擎的判定調低。

## 擴充功能的權限

| 權限 | 用途 |
|---|---|
| 存取所有網站（`<all_urls>`） | 在每個網頁和 iframe 裡攔截剪貼簿寫入、檢查貼上的內容。不讀取網頁的其他內容 |
| `storage` | 儲存你的設定和攔截摘要 |
| `offscreen`（只有 Chrome） | 需要覆寫剪貼簿時使用 |

PasteWarden **不要求** `tabs`、`history` 等權限，也不讀取你的瀏覽紀錄。
